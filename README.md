# Netflix Clone

A Netflix-inspired streaming UI built with **React + Vite**, powered by the **TMDB API**. Features a hero banner, category rows, and in-app trailer playback via YouTube.

🔗 **Live Demo:** [https://netflix-clone-tsion2.vercel.app/](https://netflix-clone-tsion2.vercel.app/)

---

##  Features

- **Hero Banner** — Random Netflix Original with backdrop, title, and synopsis
- **Trailer Playback** — Click Play on the banner or any movie card to open the YouTube trailer in a modal
- **Category Rows** — Trending, Netflix Originals, Action, Top Rated, Comedy, Horror, Romance, Documentaries
- **Hover Cards** — Movie cards reveal a richer hover state with action icons
- **Responsive Layout** — Works on desktop, tablet, and mobile
- **Live TMDB Data** — All content fetched in real time from The Movie Database

---

##  Tech Stack

| Layer | Technology |
|---|---|
| Frontend | React 18 |
| Build Tool | Vite |
| HTTP Client | Axios |
| Icons | react-icons, lucide-react |
| Styling | CSS Modules |
| API | The Movie Database (TMDB) |
